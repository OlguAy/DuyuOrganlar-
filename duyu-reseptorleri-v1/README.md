# Duyu Reseptörleri

11. sınıf biyoloji projesi için hazırlanmış etkileşimli React + TypeScript uygulaması.

## Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda Vite'ın gösterdiği yerel adresi açın.

## Mevcut Milestone

- Öğrenci adı / sınıf girişi ve localStorage oturumu
- Ana menü: Öğren / Oyun
- Veri odaklı duyu organı registry yapısı
- Göz modülü
  - Göz
  - Fotoreseptör
  - Nöron
- Etkileşimli CSS/SVG-benzeri sahneler ve sinyal animasyonları
- Ortak InfoPanel ve ProcessStepper
- Kulak, burun, dil ve deri için genişletilebilir modül yerleri

Oyun bölümü ve diğer duyu organlarının ayrıntılı sahneleri sonraki milestone için bırakılmıştır.
